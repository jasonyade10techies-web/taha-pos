# Auth feature boundary

The existing session store and shell retain the Supabase Auth/server permission foundation. Phase 2 runs in explicit local demo mode with IndexedDB profiles, configurable demo permissions, a public demo switching/approval PIN and local profile editing. These are workflow simulations, not production authentication. No customer signup is offered.

See the main README and `docs/LOCAL_ARCHITECTURE.md` for the current prototype. `supabase/README.md` and `docs/SUPABASE_SETUP.md` describe the retained future server foundation; no hosted backend was connected in this phase. Live business repository adapters must be completed before production use.
